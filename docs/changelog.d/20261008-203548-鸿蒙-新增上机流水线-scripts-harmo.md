## 2026-10-08（鸿蒙：新增上机流水线 `scripts/harmony.sh`（H0））

- **背景**：鸿蒙此前"构建→装→起→看日志→抓崩溃"全是**手敲命令**（散在 `apps/harmony/README.md` 里），
  既不可复现、也容易漏步骤（如"已在运行时 `aboutToAppear` 不会重跑"这个坑）。
  Android/iOS 侧早有 `scripts/android.sh` / `scripts/ios_app.sh`，鸿蒙缺对等物。
  这也是方案 §3 的 **H0** 阶段产物、且是方案 §7 交接里"开工前先做"的第 3 件事。

- **改动**：新增 `scripts/harmony.sh`（可执行），子命令：
  - `build`：委托 `scripts/harmony_spike.sh all`（KMP 产物 + HAP，自带 `verify_no_tensor_setdata` 守卫）；
  - `install`：把**未签名** `entry-default-unsigned.hap` 装到模拟器；
  - `start`：`aa start -a EntryAbility -b com.sekb.ohos.spike`；
  - `selftest [秒数]`：**先 `aa force-stop`**（否则已在运行时不重跑 `aboutToAppear`）→ start → 等 N 秒 → 抓 `hilog`；
  - `log`：按 TAG 过滤最近的 hilog；
  - `crash [--save]`：列 `/data/log/faultlog/faultlogger/`，`--save` 把最新一条拉回 `docs/tmp/`；
  - `all`：`build + install + selftest`。
  脚本头部把现场事实写死在注释里（hdc 不在 PATH、模拟器由 DevEco IDE 起、实例是 **arm64**、
  未签名可装、崩溃栈位置、`set -u` 下 `$VAR` 紧贴中文标点会被当成变量名+高字节 → **变量一律写 `${VAR}`**）。

- **验证**（在本机模拟器上实跑，2026-10-08）：
  - `bash scripts/harmony.sh selftest 20` → 识别设备 `127.0.0.1:5555`、`start ability successfully.`，抓到
    ```
    I A00000/SEKB_KN_SPIKE: NAPI->KMP ok: ping=42
    I A00000/SEKB_KN_SPIKE: mindspore selftest elemNum=262144 firstFloat=173347
    ```
    即**一条命令复现了 M6 的运行时证据**（NAPI↔KMP + MindSpore 推理）；
  - `bash scripts/harmony.sh crash` → 列出 `cppcrash-com.sekb.ohos.spike-20020065-20261008163155115.log`
    （**修复前**那条；修复后无新增，与 README 记录一致）；
  - `bash -n scripts/harmony.sh` 通过；`doc_guard.sh` 全过（6/6）。
  - 未验：`install` 分支（当前包已在设备上，未重复安装）与 `build` 分支（本轮未重跑，历史上多次绿）。
