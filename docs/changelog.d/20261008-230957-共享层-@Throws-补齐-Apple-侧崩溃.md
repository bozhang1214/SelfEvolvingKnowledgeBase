## 2026-10-08（共享层补 `@Throws`：Apple 侧"非 2xx 就崩"的真根因；另加两条机械守卫）

- **背景（有实测证据，不是推断）**：iOS 侧交付时发现——`SekbApi` 抛出的 `SekbApiException`
  跨到 Swift 时**没有 `@Throws` 声明**，Kotlin/Native 直接终止进程。子代理 B 用一个探针在
  macOS framework 上跑出原始输出：

  ```
  Function doesn't have or inherit @Throws annotation and thus exception isn't propagated
  from Kotlin to Objective-C/Swift as NSError ... Program will be terminated.
  Uncaught Kotlin exception: com.sekb.shared.net.SekbApiException: SEKB 500: probe-500
  Abort trap: 6
  ```

  后果不是"报错难看"，而是**架构退化**：iOS 为了不崩，重写了一份 `SekbApiBridge.swift`
  （248 行，把 5 个协议路径 + 响应字段解析又抄了一遍）——正是 RFC 最反对的"制造第二套事实"。
  触发场景很常见：**token 过期（401）**就会走到这条路。

- **改动**：
  1. `SekbApi`：8 个公开方法全部标 `@Throws(SekbApiException::class)`
     （login / enroll / refresh / heartbeat / listDevices / chatStream / reportRouteEvent / routeStats），
     并在类 KDoc 里写明"新增公开方法必须标"。
  2. 同类缺口一并补：`Json.getString/getInt/getJSONObject/getJSONArray`（缺失即抛 → `NoSuchElementException`）、
     `HostOllamaEmbedding.embed`（HTTP/字段异常 → `IllegalStateException`）。
  3. `scripts/check_edge_facts.py` 新增两条检查：
     - **`@Throws` 守卫**：共享层**公开**方法体内有 `throw` 却缺 `@Throws(...)` → 报错
       （private/protected 不跨语言，不要求；检测器按**函数声明作用域**判定，不是"找最近的 fun"）。
     - **注释块语法守卫**：行首 ` *` 出现在块注释之外、或块注释未闭合 → 报错。
  4. **修掉我自己引入的一次构建级破坏**：给 `SekbApi` 追加 `@Throws` 说明时，脚本把 `*/`
     插到了 KDoc 中间 → 第 26–33 行的 ` * …` 落在注释外，成为顶层语法错误
     （`e: SekbApi.kt:33:17 Syntax error: Expecting a top level declaration.`）。
     后果是**所有端**的构建一起失败（iOS / Mac / 鸿蒙都链接 `:shared`），而 iOS 侧那轮构建
     跑了 17 分钟才报出来。已修正注释，并用上面第 2 条守卫把这类断法挡在提交前。

- **验证**：
  - `python3 scripts/check_edge_facts.py` → `commonMain JVM 专有 API 0 处`、
    `缺 @Throws 0 处`、`注释块语法问题 0 处` ✅；
  - **反向验证（能抓住当时那个真实破坏）**：把那个多余的 ` */` 注回 `SekbApi.kt`
    → 守卫逐行报出 `SekbApi.kt:26…34 行首是 * 但不在块注释里` 并退出 1；还原后回绿；
  - **反向验证（Throws）**：去掉 `Json.getString` 的 `@Throws` → 守卫报错退出 1；还原后回绿；
  - **编译验证**：`:shared:compileAndroidMain` BUILD SUCCESSFUL；
    `bash scripts/android.sh test` → BUILD SUCCESSFUL（292 用例 / 0 失败）。
  - 另注：`SekbApiBridge.swift` 因此**具备整体删除条件**（改回共享层 `SekbApi`），
    但那是改 `SekbContainer` + 自检项的回归风险动作，安排为下一轮单独提交。
