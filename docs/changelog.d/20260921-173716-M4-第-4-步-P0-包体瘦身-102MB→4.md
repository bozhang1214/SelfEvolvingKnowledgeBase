## 2026-09-21（M4 第 4 步：P0 包体瘦身 102MB→41.6MB + 自检 27/27，含 R10 运行时证据）

- **背景**：审计包体时发现最该做的三件事里有两件与跨端无关、且当天就能做完：
  onnxruntime 的 AAR 默认带 **4 个 ABI（70.4 MB，占 APK 69%）**、PDFBox 传递依赖把
  BouncyCastle 的后量子密码参数文件（≈6.7 MB）打进了包——而端侧只用 PDFBox 抽文本层。

- **改动**：
  - `apps/android/app/build.gradle.kts`：`splits.abi { include("arm64-v8a") }`（本项目唯一在用的
    模拟器镜像就是 arm64-v8a，真机也全是 arm64；需要 x86 模拟器时改一行即可）；
    `packaging.resources.excludes += "org/bouncycastle/pqc/**"`。
  - `SelfTest.kt` 新增 `privacy_device_only_local_gate`：DEVICE_ONLY 请求在**非本机**端点下
    必须零调用（用计数假 EdgeLlm 断言）。

- **验证（实测数字）**：
  | 项 | 改前 | 改后 |
  |---|---|---|
  | debug APK | **101,945,162 B（≈102 MB）** | **41,595,392 B（≈41.6 MB）**（−59%） |
  | APK 内 ABI | 4 个 | **仅 arm64-v8a** |
  | ONNX 原生库 | 70.4 MB | **17.6 MB** |
  | BouncyCastle PQC 参数 | ≈6.7 MB | **0**（`unzip -l \| grep -c pqc` = 0） |
  | 模拟器自检 | PASS=26 | **PASS=27 FAIL=0 SKIP=1** |
  - 自检新项输出：`[PASS] privacy_device_only_local_gate — edgeBaseUrl=http://10.0.2.2:11434/v1
    本机=false 端侧调用=0 原因=escalation_blocked:device_only_requires_local_runtime 输出长度=0`
    → R10 不只在单测里成立，**在真机/模拟器运行路径上也成立**。
  - 顺带验证"排除 PQC 不影响 PDF"：`rag_pdf_extract` / `rag_import_pdf` / `rag_pdf_delete` 仍全 PASS。

- **未做（有意）**：release 开 R8 —— dex 仍 ~66 MB，是下一个大头，但需要**签名的 release 包 + 一轮
  E2E 验证**才能确认 keep 规则不缺；留到能跑完整验收的轮次，避免"体积好看了、运行时崩了"。

- **文档同步**：`apps/android/docs/VERIFICATION.md` 新增 §1.0（契约夹具 + R10）、§1.0.1（P0 瘦身 + 自检 27/27）；
  全仓 `26/26` → `27/27`、单测数 → 191 已同步（RFC / KMP 方案 / Android README）。
