- **背景**：R10 先在客户端落地（DEVICE_ONLY + 非本机端侧端点 = 一个请求都不发）。owner 已确认把

    时**直接抛错，一个请求都不发**（流式若先吐了 token 就收不回，所以必须在决策处拦）。
