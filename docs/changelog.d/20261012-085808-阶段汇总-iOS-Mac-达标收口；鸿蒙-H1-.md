- **值得单独记的一条（方法论语）**：H6 的旧结论是"转换产物在运行时忽略掩码输入"，依据是
  ① 掩码取值扫描四个值结果相同、② host 与设备不一致。**两条都不成立**：
  ① 那四个值（`-1e9/-65504/-1e4/-inf`）在 host 上**也**给出相同余弦（softmax 饱和）；
  ② 真因是设备侧把 **int32** 的 token 输入按 `LongArray` 的 8 字节写、**越界 2048 B**，
  于是模型只读到前 256 个 id。修正后 host 与设备都回到 `cos=0.2439`。
  **教训**：把"某两条实验支持 X"当成 X 成立之前，先问"这两条实验对别的解释是否同样成立"。
