## 2026-10-09（撤回 `@Throws` 修法：嵌入失败改为「同数量零向量」；并补上 native 编译检查）

- **背景（这是一次自我纠错，三方实测都摆在这里）**：
  上一轮我为了修"Apple 侧异常跨语言崩溃"，给共享层补 `@Throws`。其中
  `EmbeddingProvider` 那处**改错了方向**，造成两次真实构建破坏：

  | 我的写法 | 报错 | 后果 |
  |---|---|---|
  | `@Throws` 只标在 **override**（`HostOllamaEmbedding.embed`） | `Member overrides different '@Throws' filter from 'interface EmbeddingProvider : Any'` | **Kotlin/Native 硬编译失败**；JVM 宽容 → `:shared:compileAndroidMain` 绿、292 单测绿，只有 iOS/鸿蒙挂（各跑 17–18 分钟才报） |
  | 子代理 C 改成标在**接口**上 | 编译通过 | 但把契约从"失败即降级"改成"失败即抛"，**与既有不变量冲突** |

  关键事实（决定了正确修法）：**`EmbeddingProvider.embed` 的既有契约是"失败返回同数量零向量"**——
  Apple 侧 `OrtBgeEmbedding.embed` 一直是"捕获异常 → 零向量 + `lastError`"，且有实测教训：
  返回**空/短**数组会让 `KnowledgeIndex.ingest`（按切片数索引）**下标越界崩溃**
  （`EXC_BREAKPOINT`，栈顶 `Kotlin_NSArrayAsKList_get`）。
  而共享层 `HostOllamaEmbedding` 与 Android `OnnxBgeEmbedding` 当时是**直接抛** →
  **同一个接口两种失败语义**：宿主故障时 iOS 降级、Android 崩。这本身就是缺陷。

- **改动（选定"用返回值表达失败"这条）**：
  1. `HostOllamaEmbedding.embed`：改为 `try { … } catch { 记 lastError；返回 texts.size 个零向量 }`；
     新增 `lastError`（与 Apple 侧 `OrtBgeEmbedding.lastError` 同口径）；条数不符也算失败。
  2. `EmbeddingProvider.embed`：**不标 `@Throws`**，并把两条路为什么不行的实测结论写进 KDoc
     （override 上标 → native 编译失败；接口上标 → 契约反转，崩回 `ingest`）。
  3. `scripts/verify_all_ends.sh`：**新增 native 编译检查**（`:shared:compileKotlinMacosArm64`
     + `-PsekbNativeTargets=true`）——这正是让这个错连撞两次的洞：
     **"Android 编得过"不等于"共享层编得过"**。同时修了脚本自身的环境缺口
     （`KONAN_DATA_DIR` 必须指仓库内，否则读 `~/.konan/*.lock` 报 `FileNotFoundException`，
     而且失败在配置阶段、整轮白跑 16 分钟）。
  4. `scripts/check_edge_facts.py`：`@Throws` 守卫细化——
     ① 函数**自己 catch 掉的 throw** 不算（`HostOllamaEmbedding` 这种"内部抛、外部不抛"）；
     ② **新增接口/override 过滤器一致性检查**：只在 override 上标 → 直接报
     "Kotlin/Native 会编译失败"（这类错只在 native 暴露，值得一条 30 毫秒的静态检查）。

- **验证**：
  - **反向验证**：把 `@Throws` 注回 override（复现 c3fecb7 的写法）→ 守卫报
    「`embed()` 在 override 上有 `@Throws` 而接口没有 → **Kotlin/Native 直接编译失败**」并退出 1；还原回绿；
  - **native 编译（决定性证据）**：`./gradlew -PsekbNativeTargets=true :shared:compileKotlinMacosArm64`
    → **BUILD SUCCESSFUL**（撤回接口 `@Throws` + 零向量降级后）；
  - `python3 scripts/check_edge_facts.py` → JVM 专有 API 0 处、缺 `@Throws` 0 处、注释块 0 处 ✅；
  - `bash scripts/verify_all_ends.sh quick` → 新增的 native 项通过（`SEKB_SKIP_NATIVE=1` 可显式跳过并记 SKIP）。
  - ⚠️ 遗留：本轮**未**给 `KnowledgeIndex.ingest` 加"嵌入条数不符就跑成零向量"的防御断言，
    该加固记入下一轮（现在的契约是"实现必须返回同数量"，靠这条测试守住）。
