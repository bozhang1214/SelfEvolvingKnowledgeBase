## 2026-09-23（职位源：猎聘服务器 IP 被风控封禁（扩搜副作用）与排查结论）

- **背景**：为 FDE 全量调研连续跑了多轮「22 关键词 × 翻页」扫描。最后一轮（11 源完整重扫）
  发现来源分布里**猎聘为 0**——而当天早些时候猎聘还能返回 184 条。**这是本次操作的副作用，
  如实记录并排查。**

- **现象与诊断**：
  - 猎聘搜索接口返回**裸拒绝** `{"flag":0}`（HTTP 200、`content-type: text/json`，
    无 `code`/`msg`，`resp.json()` 正常解析，**不是结构变化**）；
  - 浏览器打开搜索页会 302 到
    `https://safe.liepin.com/page/liepin/captchaPage_ip_PC?euuid=ZmxhZzEwMDAxfGlwX3VhOjQ5LjIzMg...`，
    页面文案：「猎聘安全中心发现您的**帐号或 IP** 可能存在异常…请进行安全验证」；
  - `euuid` base64 解出为 `flag10001|ip_ua:49.232...` —— **按 IP + User-Agent 标记**，非账号问题。

- **排除过的假设（都不是原因）**：

  | 假设 | 实测结果 |
  |---|---|
  | 请求头不够像浏览器 | ❌ 补 `sec-ch-ua` / `sec-ch-ua-platform` / `Sec-Fetch-*` / `priority` 后仍 `{"flag":0}` |
  | 短时高频限流 | ❌ 间隔 15s 重试仍 `{"flag":0}` |
  | 接口契约变更 | ❌ 返回裸拒绝而非结构变化 |
  | Cookie / 令牌缺失 | ❌ `acw_tc` / `__gc_id` / `XSRF-TOKEN` 三步流程与封禁前一致，仍被拒 |

- **结论**：**服务器 IP `49.232.42.91` 被猎聘的阿里云 WAF 按 IP+UA 标记**，
  触发原因是当天对猎聘的累计请求量（多轮 22 关键词扫描，每轮 1 次首页 GET +
  1~2 次搜索 POST）。**这是扩搜操作的直接后果。**

- **影响**：
  - 猎聘是唯一免登录可用的通用招聘平台（BOSS 需登录、智联虽可用但结果偏杂），
    它一度为 FDE 集贡献 **49/101** 条岗位；
  - **数据未丢失**——扩搜整合用的是**并集**（`最终集 = 现有集 ∪ 新筛出集`），
    因此本次重扫中 50 条「未再出现」的岗位（主要是猎聘岗）**全部保留未删**；
  - 后续搜索会缺猎聘这条线，通用渠道暂时只剩智联。

- **本提交只做文档记录，不含代码改动**（`docs/ops/10-JOB-SOURCES.md` 新增猎聘章节）。
  可选解法已写入该章节，按推荐度排序：
  1. **给采集编排加节流**（治本）：`JobCollector.fetch_all` 目前逐关键词串行，但
     **关键词之间没有延迟**，且同一关键词内各源并发——没有最小间隔与重试退避，
     单轮扫描就能把某个源打爆；
  2. 等风控自行解除（阿里云 WAF 的 IP 标记通常数小时~数天）；
  3. 仿 BOSS 加猎聘浏览器源、人工过一次验证码后复用 Cookie（IP 标记仍在时同样会被拦）；
  4. 把 22 词一轮拆成多轮、每轮间隔几分钟。

- **给后续操作的硬约束**：**不要再对猎聘做连续多关键词扫描**。扩搜优先用
  「少量关键词 + 多轮间隔」，或先用智联 / 大厂官方站凑量，猎聘只作补充。

- **验证**：`bash scripts/check_kernel.sh` 无关；本次无代码改动，故门禁不适用。
