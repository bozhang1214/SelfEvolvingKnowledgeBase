    **不复制任何 .kt**；spike 的 settings `include(":shared-core")`。**`apps/shared/build.gradle.kts` 一行未改**。
  - **H1 · 三个 actual**：`apps/shared-core/src/ohosMain/kotlin/` 里 `Clock.ohos.kt`（libc `time()`）、
    `Hmac.ohos.kt` + `com/sekb/ohos/Sha256Pure.kt`（**纯 Kotlin SHA-256/HMAC-SHA256**）。
    选型依据（有实测）：`CryptoArchitectureKit` 的 sysroot 头文件与导入桩齐全（`libohcrypto.so`，
    `Digest` 自 API 12 / `Mac` 自 API 20），但设备侧可得性**当时无法证明**（`hdc shell test -e` 受限，
    对已确认在跑的 `libmindspore_lite_ndk.so` 也报 MISSING）→ 改为零依赖实现 + RFC 4231/FIPS 180-4 公知向量逐位验证。

  - **H1 · 冒烟**：`sekb_spike_smoke`（NAPI `smoke()`）把 11 项结果打到 hilog；新增
