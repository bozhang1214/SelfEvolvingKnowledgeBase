## 2026-09-25（release 开 R8：dex 64.7 MB → 2.8 MB、APK 43.3 MB → 20.8 MB）

- **背景**：§1.0.1 留下的结论是"未做：release 开 R8（dex 仍约 66 MB，是下一个大头）"。本轮做掉。
  量体积不需要装包，因此不受真机安装受限（手机要求生物识别验证）的影响。

- **改动**：`release { isMinifyEnabled = true; isShrinkResources = true }`
  （shrinkResources 只在 minify 打开时才有意义）；`proguard-rules.pro` 加
  `-dontwarn com.gemalto.jp2.JP2Decoder`。

- **唯一阻塞（R8 自己给出答案）**：`Missing class com.gemalto.jp2.JP2Decoder`
  （由 tom_roush PDFBox 的 JPXFilter 引用的**可选**依赖，只有解析 PDF 内嵌 **JPEG2000 图像**时才需要）。
  本项目的 `PdfExtractor` 只用 `PDFTextStripper` 抽文本、**不走图像路径** → 加 `-dontwarn` 剥离它，
  而不是为一个用不到的解码器把包体做大。**残留限制**：将来若要提取 PDF 内嵌 JPEG2000 图像，
  必须加回 `jp2-android` 依赖，否则该路径运行时抛错（当前无此需求）。

- **结果（arm64 实测）**：
  | | debug | release(R8) | 降幅 |
  |---|---|---|---|
  | APK | 43.3 MB | **20.8 MB** | **−52%** |
  | dex 合计 | 64.7 MB | **2.8 MB** | **−96%** |

- **已验证/未验证**：
  - ✅ 体积实测；`scripts/android.sh` 新增可复现的 `release` 动作。
  - ✅ R8 未删自检入口：mapping 有 `SelfTest.*`、release dex 仍有 `SEKB_SELFTEST` 字符串
    → 签名后的 release 包仍可跑自检做 E2E；`MainActivity`/`PDFTextStripper` 也都在 mapping 中。
  - ❌ **"R8 后能不能正常跑"未验证**：产出未签名 APK（装不上），且当前手机装包需生物识别验证。
    闭环需：① 给 release 配签名（可复用 `.tooling` 的 debug keystore 仅联调）；② 装机跑自检 E2E。

- 验证：doc_guard 6/6；shell lint 未超基线。
