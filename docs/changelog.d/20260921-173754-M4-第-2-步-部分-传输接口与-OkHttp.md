## 2026-09-21（M4 第 2 步（部分）：传输接口与 OkHttp 实现分文件，为 KMP 端口铺路）

- **背景**：`HttpTransport` 是四端共用的**端口**（要搬进 KMP `shared`），而 OkHttp 是 JVM/Android 专有实现。
  两者原先在同一个文件里——抽 shared 时必然要先拆，不如现在拆：接口文件里**不出现任何 okhttp 符号**，
  才能在 iOS/鸿蒙编译。
- **改动**：`net/HttpTransport.kt` 只留 `HttpResponse` + `HttpTransport` 接口；
  新增 `net/OkHttpTransport.kt`（实现 + 默认客户端），文件头写明 iOS 侧对应 NSURLSession、
  鸿蒙侧对应 libcurl（见 `docs/多端跨端-工程议题（网络层·包体·热修复）.md` §1）。
- **验证**：`bash scripts/android.sh test` → **191 tests, 0 failed**（行为零变化，纯文件拆分）。
- **下一步**：`org.json` 收敛到 `JsonX` 门面（12 个文件直接用 `org.json`），
  以及 `File/UUID/concurrent` 的多平台替换——这两件做完，`shared/` 才搬得动。
