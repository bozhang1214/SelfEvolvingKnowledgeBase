## 2026-09-21（M4 第 5 步：KMP 共享模块落地——apps/shared，202 测试 + 自检 27/27 全绿）

- **背景**：M4 前四步把"一致性"（契约夹具）、"隐私硬边界"（R10）、"包体"（P0 瘦身）、
  "去平台化"（org.json/okhttp/File/UUID 收进端口）做完后，才轮到真正建 KMP 模块——
  因为模块一旦建起来，任何平台泄漏都会在 iOS 编译时爆出来，顺序不能反。

- **改动**：
  - 新增 `apps/shared`（Kotlin Multiplatform）：`commonMain` 放 **26 个文件 / 3,395 行纯逻辑**
    （路由决策、升级信号、前缀守卫、工具校验、编排、分块、向量数学、检索、SSE 解析、协议客户端、
    评测集、JSON 门面、常量）；**平台实现全部留在 `apps/android/app`**（Compose UI、OkHttp、Keystore、
    SQLite、ONNX、设备工具、装配、自检）——shared 保持**零平台依赖**。
  - `core/Json.kt` 底层从 org.json 换成 **kotlinx-serialization-json 1.8.1**（JVM 与 native 都有产物），
    于是 **org.json 彻底退出项目**（此前只是"关在一个文件里"）；API 与调用点一行没改。
  - `core/Ids.kt` 去平台化：`java.util.UUID` → `kotlin.random.Random`（端侧本地标识，不参与安全判定）。
  - 构建接线：`:app` → `:shared`；`apps/android/settings.gradle.kts` 里 `include(":shared")` +
    `projectDir = file("../shared")`（wrapper 与 CI 都不用动，Q7 的"上移 wrapper"因此**没必要**）。
  - `scripts/android.sh`：新增 `KONAN_DATA_DIR=$ROOT/.tooling/konan`。
  - native target（iOS/Mac）**默认关闭**，`-PsekbNativeTargets=true` 打开（理由见下）。

- **验证（本机实测）**：
  - `bash scripts/android.sh test` → **202 tests, 0 failed**（测试仍在 app 模块，测的却是 `:shared` 里的代码，
    证明依赖方向与可见性正确；只有 1 处需要改：跨模块无法 smart cast）。
  - `bash scripts/android.sh assemble` → `app-arm64-v8a-debug.apk` **45.4 MB**。
  - 模拟器 E2E：`install` + 自检 → **PASS=27 FAIL=0 SKIP=1**（含 R10 项），**证明改了 SDK 根之后整条链路没坏**。
  - 平台泄漏自检：`shared/src` 里没有 `android.*` / `java.*` / okhttp / onnxruntime 的 import。

- **三个环境坑（都解决了，写进 VERIFICATION §1.0.3，否则下一个人会重踩）**：
  1. **AGP 9 明确禁止 `com.android.library` + KMP** → 必须用 `com.android.kotlin.multiplatform.library`；
  2. 该插件**没有 `compileSdkMinor`**，本机只有 `platforms/android-36.1` → 在仓库内 `.tooling/android-sdk`
     造了一个 `platforms/android-36`（android.jar 软链 + 改写 `source.properties`/`package.xml`），
     `local.properties` 指向它（**不入库**）；**系统 SDK 一个字节都没动**；
  3. Kotlin/Native 默认写 `~/.konan`（工作区外，沙箱拒绝）→ `KONAN_DATA_DIR` 收进 `.tooling/`。

- **native target 现状**：`-PsekbNativeTargets=true :shared:compileKotlinIosSimulatorArm64` 会触发
  Kotlin/Native 工具链下载（Maven 上的 `kotlin-native-prebuilt`，阿里云镜像有货）。首次尝试已越过
  "写 ~/.konan 被拒"这一关，正在后台探完整下载与编译；**结论会补进本文件**。iOS 端（M5）以此为前置。
