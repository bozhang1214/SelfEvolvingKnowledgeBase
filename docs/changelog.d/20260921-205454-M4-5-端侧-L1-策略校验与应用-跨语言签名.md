## 2026-09-21（M4.5 端侧：L1 策略校验与应用——跨语言签名向量 + HMAC/SHA256 端口）

- **背景**：服务端 `/edge/policy` 已能下发签名策略；端侧必须**自己**验签、校验并应用，
  否则"热修"就是"服务端说啥就是啥"。按 owner 确认的范围：先接 config 类
  （阈值/信号/预算/模型档位/工具白名单），`promptPacks` 后置。

- **改动（共享层）**：
  - `policy/EdgePolicy.kt`：验签 → 有效期 → 空间戳 → 白名单（未知键**整包拒绝**；
    `deviceProfiles` 预留但**不读取**）→ 灰度 → 合并进 `EdgeRuntimeConfig`。
    结果类型区分 `Applied(config, version, appliedKeys, ignoredKeys)` 与 `Rejected(reason)`——
    **如实报告"哪些没应用"**：`retrievalMinScore` 不在 `EdgeRuntimeConfig` 里（属 Retriever 构造参数），
    进 `ignoredKeys` 并提供 `retrievalMinScore()` 专用读取口。
  - `core/Hmac.kt`：新增 `hmacSha256Hex` / `sha256Hex` 两个端口（expect + androidMain
    `javax.crypto.Mac`/`MessageDigest` + appleMain `CCHmac`/`CC_SHA256`）。
    灰度必须用 **sha256**（与服务端同式）——Kotlin 内置 `hashCode` 跨进程不稳定，会让灰度"今天命中明天不命中"。
  - 规范化 JSON：键递归排序 + 紧凑分隔符 + 非 ASCII 不转义，与 Python
    `json.dumps(sort_keys=True, separators=(",",":"), ensure_ascii=False)` **逐字节对齐**。

- **验证**：
  - 新增 `EdgePolicyTest` **14 条**：**跨语言签名向量**（签名由服务端 Python 生成后硬编码）、
    HMAC/SHA-256 公知向量、篡改/换钥/空间不符/过期/白名单外键/非 JSON 的拒绝路径、
    预留字段放行但不读取、灰度确定性与比例、规范化 JSON 与 Python 一致。
  - `bash scripts/android.sh test` → **221 tests, 0 failed**；
  - `-PsekbNativeTargets=true` → iOS/macOS 编译 **BUILD SUCCESSFUL**；
  - Apple cinterop 两个坑记进代码注释（`allocArray<UByteVar>` 索引读需额外 import → 改用
    `usePinned` + 地址传 C；`CC_SHA256` 要无符号指针 → `reinterpret<UByteVar>()` 且需显式类型实参）。

- **还没做（下一步）**：拉取时机（启动 + 每 6h + 自检项手动触发）、双槽持久化（`PolicyStore` 端口 +
  各端实现）、审计落盘；`promptPacks` 接入真实 LLM 调用点（单独一轮）。
