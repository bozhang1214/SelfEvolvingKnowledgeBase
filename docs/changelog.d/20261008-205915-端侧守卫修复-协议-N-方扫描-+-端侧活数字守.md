## 2026-10-08（端侧守卫两处修复：协议扫描根失修 + 端侧活数字无守卫）

- **背景**：本轮是"四端收口"开工的第一件事——**先把守卫修好，再让三端并行动手**。
  两个问题都不是"看起来不对"，而是**守卫自己在骗人**：

  1. **协议守卫的客户端扫描根失修**：`scripts/check_protocol_paths.py` 仍指向
     `apps/android/app/src/main/kotlin/com/sekb/ondevice/net/SekbApi.kt`，而端侧客户端
     **早已搬进共享层**（`apps/shared/.../net/SekbApi.kt`，四端共用一份）→
     `client_paths()` 静默返回空集，输出「客户端调用 **0** 个」却报 ✅。
     **修正扫描根后立刻抓出真缺口**：`/api/v1/edge/policy` 在服务端与端侧都已实现，
     但**协议文档从未声明**（协议文档是端云两侧的唯一契约，客户端能调的端点必须在里面）。
  2. **"活数字"只有"多处矛盾"守卫，没有"实际值"守卫**：`check-facts.py` 只能发现在
     不同文档里取值**互相矛盾**；抓不到更常见的漂移——**所有文档都写着同一个过时的数**。
     实测就是这种：`fact:android_unit_cases=231` 被 **4 份文档**引用（`apps/android/docs/VERIFICATION.md`、
     `apps/android/README.md`、`docs/RFC-多端跨端方案.md`、`docs/多端跨端-鸿蒙端方案.md`），
     而 `@Test` 静态计数与 Gradle XML 报告**都是 291**；共享层规模「35 文件 / 4,066 行」实测 **37 / 4,394**。

- **改动**：
  - `scripts/check_protocol_paths.py`：客户端改为**扫描根列表**（共享层 + Android + iOS + Mac + 鸿蒙，
    后缀 `.kt/.ets/.ts/.swift`），跳过构建产物/第三方目录；**必需的扫描根不存在即报错、
    扫到 0 个来源也报错**（不让守卫假绿）；输出改为「N 方」并打印**源文件数**，让"真的扫到了东西"可见。
  - `docs/ops/16-端云协同协议.md`：补 **§5.1 `GET /api/v1/edge/policy`**（L1 策略下发）——
    鉴权按设备、`rollout_percent`、返回体自校验，以及端侧三条不变量（时间戳统一 epoch 毫秒、
    空间戳由构造保证同源、非法/过期/空间不符必须拒绝并留痕）。
  - **新增 `scripts/check_edge_facts.py`**：把"文档里的端侧统计量"与"代码/测试实测值"做成硬判据。
    关键设计——**不跑测试也能复核**：`@Test` 注解数 == Gradle 用例数（实测 291 == 291），
    所以用例数可静态数出；XML 报告存在时再交叉验证一次（不一致即报错，说明有测试没被收集）。
    同时守住契约夹具的功能下界（routing≥10 / signals≥14 / privacy≥13）。
  - **接入必经之路**：`docs/tech/.validation/doc_guard.sh` 增加第 7 项（1/6→6/6 改为 1/7→7/7），
    并修好第 5 项的描述（三方 → N 方）。
  - 同步过时数字：`apps/android/docs/VERIFICATION.md`（231→291，并注明"只有这一行是权威值"）、
    `apps/android/README.md`、`docs/RFC-多端跨端方案.md`（三处）、`apps/README.md`（共享层规模 + 四端状态表）。

- **验证**：
  - `python3 scripts/check_protocol_paths.py` → `服务端路由 72 / 文档声明 15 / 客户端调用 9（来自 6 个源文件）` ✅；
  - **反向验证（守卫必须会红）**：在 `apps/mac/` 放一个含 `api/v1/edge/bogus-endpoint` 的临时 `.swift`
    → 守卫立即报 2 处（文档未声明 + 服务端不存在）并退出 1；删除后回绿；
  - `python3 scripts/check_edge_facts.py` → 实测 `android_unit_cases=291`（XML 交叉验证 291）、
    契约夹具 `privacy=13 / routing=10 / signals=14` ✅；
  - **反向验证**：把 `fact:android_unit_cases` 临时改成 999 → 报「写 999，实测 291」退出 1；还原回绿；
  - `bash docs/tech/.validation/doc_guard.sh --no-warn` → 7 项全过。
