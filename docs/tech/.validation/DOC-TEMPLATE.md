## 2. 全局编号体系

## 3. 写作纪律

1. **证据**：每条结论带 `backend/…:行号` 或 `frontend/…:行号`；引代码 ≤8 行，超出概括。
2. **推断**：标 `【推断·待验证】`。
3. **as-is / to-be 分离**：现状写正文；改进建议归 `07`/`11`，或文中单列「改进项」小节。
4. **脱敏**：密钥/内网 IP → `<REDACTED>`。
5. **表格优先**：接口/参数/配置用表格。
6. **简体中文**：术语首次出现附英文。
7. **不注水**：每节有信息增量与证据。
8. **术语一致**：与 `08-GLOSSARY.md` 严格一致。
