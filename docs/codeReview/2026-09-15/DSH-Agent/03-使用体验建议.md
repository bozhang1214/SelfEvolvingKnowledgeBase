# 使用体验优化建议（使用者视角）

> 审查者：DSH-Agent ｜ 日期：2026-09-15 ｜ 视角：**第一次使用本产品的普通用户**
> 方法：只读走查 frontend 页面/组件/store + backend 路由的错误提示与文案，对照「知识的诅咒」找「设计者以为用户懂、但新用户会懵」的地方。
> 说明：所有条目均附 `文件:行号` 证据，可直接落地到文案/交互/引导。

## 一句话结论

产品能力很强（对话内置搜职位/联网/知识库检索三种工具、周报月报长任务、职位分析多 Tab），但「知识的诅咒」集中体现在三处：**聊天页完全没暴露内置工具能力**、**多处加载失败被静默吞掉伪装成"没数据"**、**后端异常把 Python 技术细节直接外泄给用户**。
