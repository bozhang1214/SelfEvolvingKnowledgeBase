# 使用者视角功能优化建议 · 2026-09-15

> 审查方法：刻意忘掉后端实现细节，假设只是拿到产品链接的普通用户
> 覆盖场景：新用户首次使用 / 老用户深度使用 / 多端切换 / 错误恢复

---

## 🔴 严重影响（必须解决）— 8 条

| # | 功能域 | 问题场景 | 为什么这是问题 | 建议 |
|---|--------|----------|----------------|------|
| U1 | 账号与安全 | 设置页只有昵称/密码修改，找不到"删除账户"或"导出数据"入口 | 合规性风险（GDPR/个保法），用户完全失去数据掌控感——离职了要带走资料、担心泄露要销毁数据都做不了 | 设置页加"数据与隐私"卡片：①一键导出全部数据（JSON + Markdown）②删除账户按钮（二次确认+冷静期）③"系统自动抽取了哪些偏好"透明列表，可逐条关闭 |
| U2 | AI 对话 | 回复生成中只有一个跳动的小蓝点 + 变化的文字（"正在检索→规划→反思"），用户不知道总共有几步、当前第几步、还要等多久 | 等待焦虑。特别是 Planner 调 reasoner 模型，TTFT 几秒到十几秒 | ①把固定步骤做成进度条（理解→检索→规划→执行→反思→生成，共 6 步），当前步骤高亮 ②标注每步耗时（如"规划中 · 已用时 8s"）③后端预估剩余时间返回前端 |
| U3 | 账号与安全 | 注册时填完信息提交后收到模糊错误，完全没提示"您不在白名单内" | 用户体验灾难。朋友给了链接，注册失败后不知道为什么、不知道找谁要权限 | ①注册页增加"注册需管理员审批"或"邀请码"提示 ②白名单外返回明确文案"您的邮箱不在用户白名单内，请联系管理员添加"③提供"申请访问"按钮 |
| U4 | 知识库 | 分享链接只有"撤销"和"30天过期"两种控制——无法设密码、时效（7天/永久/自定义）、访问次数、查看者IP范围 | 安全风险。分享链接一旦泄露（粘贴到群、浏览器历史被窃），任何人能读走整个知识库 | 创建分享时增加：①可选密码 ②有效期选择（1天/7天/30天/90天/永久）③访问次数上限 ④查看统计面板（谁在什么时间访问过） |
| U5 | AI 对话 | 回复进行中继续输入会"排队"，但用户只看到一行小字"已排队X条"——不知道队列里有什么、能不能取消、能不能重新排序 | 信息透明度差。用户连续发 5 条后以为都发出去了，但它们在队列里排着，没有取消/调整能力 | ①把排队消息做成可折叠的队列列表（每条可单独取消或拖拽排序）②输入框 placeholder 改成"正在回复，新消息将排队发送 · 查看队列"③每条旁边加"取消"按钮 |
| U6 | 账号与安全 | 设置页写"登录有效期 90 天，到期自动续租"——但没说续租条件、没显示"上次续租时间"、没有"手动延长登录"、更没有"安全退出所有设备" | 安全感缺失。公共电脑登出后担心 token 残留；手机丢了无法远程踢下线 | 设置页增加：①"其他设备登录"面板（设备列表+远程退出单台/所有）②当前会话详情（IP/浏览器/登录时间）③"退出所有设备"按钮 |
| U7 | 账号与安全 | 用户画像系统在后台自动从对话中抽取求职偏好、技能标签，但前端**完全没有任何入口**展示"系统帮我记录了什么" | 信任崩塌。用户完全不知道自己对话里透露的信息被后台静默存储了，无法查看、修改、删除 | ①设置页加"我的画像"入口，展示所有自动抽取的偏好字段 ②每个字段加"来源对话链接"③"关闭偏好自动抽取"总开关 |
| U8 | 移动端 | Chat/Knowledge/News 是固定三栏布局，手机浏览器基本无法使用；分享链接在微信打开需要登录跳转 | 严重降低移动端使用意愿——很多人用碎片时间查知识库、看资讯日报 | ①核心页面做真正的响应式：≤768px 隐藏侧边栏+抽屉式会话列表 ②分享 viewer 免登录浏览（对话功能可要求登录） |

## 🟡 明显缺陷 — 14 条

| # | 功能域 | 问题场景 | 为什么这是问题 | 建议 |
|---|--------|----------|----------------|------|
| U9 | 新用户引导 | 登录后首页是"功能说明"卡片 + "快速上手"静态 Steps——没有"立即开始使用"的行动按钮，引导是纯文字描述 | 新用户需要自己点击卡片跳转到对应页面，心智成本高 | ①每个步骤加"立即去上传文件""立即开始对话"跳转按钮 ②首次进入时做交互式欢迎 tour（高亮侧边栏→文件上传→AI 对话） |
| U10 | AI 对话 | 会话标题自动"新对话"，用户需要**双击标题**才能重命名——没有任何视觉提示双击行为 | 用户不知道可以重命名。很多产品里双击是不明显的操作 | ①标题旁加明显的 ✎ 编辑图标 ②新建会话后自动把首条用户消息前 20 字作为临时标题 |
| U11 | AI 对话 | 技能模式（skill 字段在 API 里存在，支持通用/应聘/科技资讯三种）**前端完全没有入口** | 产品能力被隐藏。后端写好了多技能系统，前端没给用户切换按钮 | Chat 页面顶部增加"当前技能"选择器：通用模式（默认）、求职面试模式、科技资讯模式 |
| U12 | 知识库 | 三级分类是后端静态配置的——用户不能自己创建、重命名、拖拽、合并 | 分类是用户组织知识的核心方式。系统预置分类不符合我的知识结构时，只能堆在"其他"里 | 知识库侧边栏加：①右键菜单（重命名、新增子分类、合并、删除）②拖拽调整顺序 |
| U13 | 知识库 | 搜索只有一个搜索框——不支持"标题 vs 全文"、不支持分类筛选、不支持按重要性/时间排序 | 条目超过几百条时，简单关键词搜索命中率很低 | 搜索框旁加"高级搜索"折叠面板：范围/分类 Cascader/重要性≥X/时间起止/排序方式 |
| U14 | 资讯 | 日报/周报/月报的 RSS 源是后端固定的——用户无法查看有哪些源、无法增减、无法调权重 | 用户对资讯内容控制力为零 | 资讯页加"资讯源管理"入口：①列出所有 RSS 源+开关+权重 ②"添加 RSS 源"表单 ③显示"最近更新时间"和"被引用次数" |
| U15 | 资讯 | 手动触发生成后前端只有一个 loading spinner——不知道进度百分比、不知道当前步骤（抓RSS/提取正文/LLM生成/写文件） | 周报/月报实际耗时 10 分钟以上，用户以为卡了 | 进度面板：①进度条 ②当前步骤文字（"正在抓取 12 个 RSS 源"、"LLM 生成头条...约 60%"）③"预估剩余 X 分钟" |
| U16 | 职位分析 | 说"9 家免登录渠道"但用户不知道具体哪 9 家、每个渠道采集到多少、失败原因是什么 | 采集到 0 个职位时用户只知道失败了，不知道是关键词不对还是渠道反爬了 | 采集结果面板加渠道明细卡片：每个渠道——名称、X 个、Y 秒、状态（成功/失败/限流）、失败原因 |
| U17 | 职位分析 | JD 粘贴后等待 30s~2min，只有 loading——不知道系统在做什么 | JD 深度分析是多步骤 LLM 调用，用户盯着转圈 icon 以为卡了 | ①把 9 个分析维度做成分步进度：step1→step2→...→done ②每步显示"LLM 正在分析 XX...约需 X 秒"③返回结果时标注缓存状态和本次耗时 |
| U18 | 职位分析 | 投递冷却期提醒是**被动的**——只有用户打开页面才能看到，系统没有主动推送 | 冷却期满的投递记录不会主动通知，价值为零 | ①系统每天扫描冷却期满记录 ②首页醒目位置显示"今日有 X 个投递冷却期满" ③可选邮件/飞书推送 |
| U19 | 错误信息 | 429 限流时只有"请求过于频繁，已自动重试"——重试后还是 429，用户只知道"失败了"，不知道被限了多久 | 用户只能反复刷新尝试，不知道该等多久 | 429 时显示：①"请等待 60 秒后再试"②倒计时（"还需等待 45 秒"）③倒计时结束自动重试一次 |
| U20 | 分享 viewer | viewer 只能浏览 + 问答——不能收藏条目、不能复制到自己的知识库、不能导出 | 降低了分享的价值密度 | ①"收藏到我的知识库"按钮（需 viewer 有账号）②"复制条目内容"按钮 ③"这个分享下我问过的问题"历史列表 |
| U21 | 通知与反馈 | 整个产品**没有反馈入口**——找不到"帮助中心"、"联系开发者"、"提交 bug" | 用户遇到问题无处表达 | ①右下角固定"?"图标点开反馈面板（bug/建议/联系）②每个错误提示加"遇到问题？点此反馈"链接 |
| U22 | AI 对话 | 消息下方操作按钮（复制/编辑/重生成/转发）**悬停才出现**——新用户完全不可发现 | 功能隐藏。新用户不知道可以重生成 AI 回复 | ①把操作按钮做成常显（hover 时高亮）②首次对话给气泡提示"💡 你可以点击 AI 回复下方的按钮重新生成答案" |

## 附：场景还原（让 Owner 有代入感）

### 场景 1：新用户 A（朋友给了链接，满怀期待）

1. 打开登录页 → 填邮箱密码 → 提交 → "登录失败" → 不知道为什么（白名单）→ 反复试两次 → 放弃
2. （如果成功）首页看到"功能说明"卡片 → 点"AI 对话" → 新建会话 → 输入"帮我分析 Agent 工程" → 等 → 只看到跳动蓝点 + 文字在变 → 不知道等多久 → 又发一条 → "已排队 1 条" → 不知道队列能取消不
3. 对话结束 → 想重命名 → 不知道要双击 → 15 个会话全是"新对话" → 放弃

### 场景 2：老用户 B（花了 3 个月，50 份 PDF）

1. 想找"Transformer 注意力机制的推导" → 搜"attention" → 200 条 → 不知道哪条是自己的推导（和网上扒的教程混在一起）→ 找不到
2. 分享了"如何部署 RAG 系统" → 忘设密码 → 链接被转发到群里 → 全公司能读 → 慌了 → 撤销 → 但不知道泄露了多少
3. 系统说"有 5 个投递冷却期满" → 找不到在哪看 → 没有通知 → 一周后想起 → 冷却期早就续了

### 场景 3：用户 C（用产品做职位分析）

1. 贴 JD → 点"开始分析" → spinner 转 2 分钟 → 出来了 → 中间刷新了一次（以为卡死了）
2. 市场报告里看到"字节·AI 应用工程师·40-80K" → 想标记主攻 → 找不到加投递计划的按钮 → 切 tab → 手动敲公司名 → 花 5 分钟
3. 想看看系统帮他记录了什么求职偏好 → 设置页找不到画像入口 → 放弃

### 最该优先做的 5 件事

1. **U2 + U15 + U17** 本质相同：把"等待黑盒"变成"透明进度条"——用户知道系统在做什么、还要多久、每步花了多少时间
2. **U7 + U28** 画像系统透明化——让用户看到并控制"系统帮我记录了什么"，这是信任基础设施
3. **U20** 分享 viewer 加"收藏到我的知识库"——让知识流动，放大分享价值
4. **U21** 加反馈入口——让开发者听到真实用户声音
5. **U14** 让用户管理资讯源——不再被动接受固定内容
